# Print-Ready Flyer Module Contract

## Scope

This standalone page duplicates **only** the print-ready flyer workflow from the Property Marketing Asset Hub. It does not include the broader photo-library download tools, ad-copy blocks, QR-code download section, floor-plan details, pricing, amenity content, income tables, or portfolio-navigation pages.

## Manager workflow

1. The manager chooses one pilot property.
2. The selected property’s approved flyer-photo grid opens from **Flyer Photo**; choosing an image applies it to the flyer immediately and displays a selection check.
3. The property name, street address, office phone number, and extension populate automatically from the verified property record.
4. The manager may adjust the referral reward and the destination encoded in the flyer QR code.
5. The live 8.5 × 11 preview remains the single primary artifact.
6. **Print Flyer** outputs only that flyer on one letter-size page. **Download PNG** outputs a high-resolution image of the flyer.

## Fixed flyer treatment

The printed artifact retains the Colonial Estates-style navy/lime referral design: the `EARN` badge, three `IT'S EASY!` steps, `It Pays to Share` offer panel, disclaimer, `Spread the Word` mark, and Equal Housing mark. Only reference-defined property data and manager-controlled reward/QR/photo fields may vary.
