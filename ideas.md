# PropertyMax Flyer Generator — Reference Specification

## Ground-Truth Reference

The user-provided `Print Property Flyer` screenshot is the visual and functional source of truth. The site is a **single, lightweight standalone webpage**, not a dashboard, asset library, or multi-step portal. Its primary job is to let a manager choose a building, set a referral amount, optionally choose a local flyer image, and then print or download that one flyer.

## Reference-Led Design Rules

The page uses a soft ivory background, a narrow content column, a modest serif page title, and a thin vertical green accent beside the heading. A pale, softly bordered instruction panel sits immediately below the heading. It contains a building selector, a compact referral-reward input, a local-image control, a dark green **Print Flyer** button, an outlined **Download PNG** button, and one line that explains the output formats.

The selected flyer is the visual focus beneath the controls. It appears as a tall 8.5 × 11 printed piece with a restrained paper shadow, not inside an application dashboard shell. A concise uppercase `FLYER PREVIEW` label introduces the artboard. There is no sidebar, no dashboard navigation, no portfolio browsing interface, no regional-manager information, and no template library.

## Product Behavior

The manager uses one property selector to choose their building. The property choice swaps the visible flyer title and approved property image. The referral amount updates the flyer’s reward message in real time. The local-image input changes the hero visual for that manager’s browser session. **Print Flyer** opens the browser print flow; **Download PNG** saves the visible flyer as a high-resolution image.

## Typography and Color

Use a refined serif headline for `Print Property Flyer` and an uncomplicated sans-serif for controls and instructions. The design is intentionally quiet: warm ivory page ground, white control panel, dark ink text, medium forest-green output buttons, and a restrained lime-green detail on the generated flyer. Generous whitespace and fine borders should keep the page calm and legible.

## Brand Essence

**A straightforward PropertyMax utility that turns a manager’s current referral offer into one ready-to-use property flyer.**

The voice is direct, helpful, and calm. Example microcopy:

> “Select your building, update the reward, then print or download a ready-to-share flyer.”

> “Your flyer is ready for the leasing office, resident event, or referral campaign.”
